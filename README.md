# my-qx-conf
下面是一个基于Quantumult X (QX) 的快捷指令配置指南。为了确保快捷指令能正常工作，**必须严格按照前两步进行设置**。

### 第一步：QX 软件内部设置
1.  打开 **Quantumult X (QX)** App。
2.  进入右下角「**其他设置**」。
3.  找到并开启「**始终打开**」选项。
4.  在 QX 首页，先手动**开启**代理开关。
5.  **重要操作**：划掉 QX 后台（彻底关闭 App 进程），确保设置生效。

### 第二步：iOS 系统 VPN 设置
1.  打开手机「**设置**」 -> 「**VPN**」。
2.  找到 Quantumult X 对应的栏目，点击后面的 **“i” (信息图标)**。
3.  **关闭**「**按需连接**」（原文称为“干预连接”）。
4.  返回 VPN 列表页，手动将 VPN 状态开关**关闭**（确保显示为“未连接”）。

---

### 第三步：添加快捷指令
根据你的需求选择一个版本添加（建议使用带菜单的列表版）：

| 版本类型 | 说明 | 下载链接 |
| :--- | :--- | :--- |
| **推荐：列表版** | 带通知，有菜单可选（开/关/切换） | [点击安装 (iCloud)](https://www.icloud.com/shortcuts/467e1c3691e0419d8249f1317900e403) |
| **切换版** | 无通知，点击即在 开/关 间切换 | [点击安装 (iCloud)](https://www.icloud.com/shortcuts/605c57b50e914c768f39dd919db271d0) |
| **仅开启** | 适合自动化（如：打开某App时触发） | [点击安装 (iCloud)](https://www.icloud.com/shortcuts/3bb4af497e374c9fa9099449fedf818d) |
| **仅关闭** | 适合自动化（如：关闭某App时触发） | [点击安装 (iCloud)](https://www.icloud.com/shortcuts/38b22ba885e74636b819c2a48356c097) |

---

### ⚠️ 注意事项与提示
* **适用版本**：原文测试环境为 iOS 17.2.1，理论上兼容临近版本。
* **自动化建议**：
    * 如果你想实现“打开 YouTube 自动开 QX，退出自动关”，请使用上面的 **[仅开启]** 和 **[仅关闭]** 两个链接配合 iOS 自带的「快捷指令-自动化」功能。
* **关于通知**：如果你不喜欢快捷指令运行时的弹窗通知，可以在安装后进入快捷指令的编辑页面，删除包含“显示通知”字样的步骤。
* **故障排查**：如果点击没反应，请检查「快捷指令」App 是否为最新版，并确认第一步和第二步的“始终开启”和“按需连接”设置是否正确。
